# Anti-Patterns Verdict

**Does it look AI-made? No.** Both assessments agree: committed green/white/black with rules actually enforced, road-sign type, unfakeable operational copy (real pickup points, "seats 4 + driver"). Residual tells: the hero photo is a very recognizable Unsplash concert image, the two-door layout is the classic recruitment pattern, and there are speed-build traces (inline styles, dead Instagram link, example testimonials).

**Deterministic scan: clean** — zero findings across all three HTML files. **In-page overlay:** 4 findings on index, 0 on app/pitch. Three are a confirmed detector false positive (it mis-parsed the green door background as white; true measured contrast of white-on-green is 4.53:1 — passing, but only by 0.03). One is genuine: `.form-card` pairs a 1.5px border with a 60px shadow blur (site.css:195), a known AI-era styling tell.

**Missed brand opportunity (A):** the brief's most ownable idea — 6:30am, dawn, the pickup point — appears nowhere on the marketing page. The venues strip could have been a pickup-points strip; no competitor could copy that.

# Overall Impression

A competent, on-brand build whose strongest asset is the run-sheet app: the WhatsApp preview bubble plus the live seat mathbar will win the Friday call. The remaining work is not visual polish — it's making the forms genuinely transmit, keeping the run sheet truthful in edge states, and giving Dee control (undo, delete, pairing).

# What's Working

1. **The WhatsApp preview bubble** — the product's output shown in its native habitat, with careful longest-tag-first @mention highlighting. The pitch-winning screen.
2. **The mathbar** — "13 crew · 3 driving · 15 seats · everyone seated ✓" converts a whole error class into ambient status.
3. **Colour discipline that survives measurement** — every checked pair clears WCAG AA (venue strip 6.33:1, crew lede 6.60:1, hero sub 5.24:1).
4. **The suggested-stop callout** — software making a judgment call in plain English with a one-tap fix.

# Priority Issues

- **[P0] Forms don't transmit anywhere.** "Sorted ✓ We've got your enquiry" is untrue unless the visitor taps the optional WhatsApp button. Fine for the Friday demo; launch-blocking for go-live. Fix: make the WhatsApp send the PRIMARY completion step ("Tap send to finish"), and/or wire FORM_ENDPOINT. Command: /impeccable harden
- **[P1] Stale/empty run sheet.** After Clear, results stay visible with zero cars and Copy produces a car-less message Dee could paste to 20+ people. Fix: hide results + Copy when no cars; reset the Build button. Command: /impeccable harden
- **[P1] Custom crew can never be edited or deleted.** A typo lives on Dee's phone forever. Fix: remove/edit on custom rows. Command: /impeccable harden
- **[P1] Phone fields accept "abc".** The number is the only channel to an applicant. Fix: soft UK-mobile pattern with existing err-msg styling. Command: /impeccable harden
- **[P2] Mobile header shows only "Hire staff".** Below 560px workers lose their door for the whole scroll. Fix: keep a compact "Join the crew" link. Command: /impeccable adapt

# Persona Red Flags

**Casey (one-handed, distracted):** "Clear" sits at thumb height beside search and wipes everything with no undo; ± time steppers are 34px (under 44px minimum); add-crew dialog opens centre-screen, not as a bottom sheet.
**Riley (stress tester):** garbage inputs sail through; "Other…" venue uses window.prompt() and silently assumes a 45-minute drive; past dates buildable. Refresh mid-flow is handled WELL (localStorage restores everything).
**Dee (coordinator):** happy path is comfortably under 60 seconds. Friction: flat 24-row roster with no drivers-first/area grouping; no way to pin "Zuri always rides with Z"; first-ever open shows 13 pre-ticked demo strangers.
